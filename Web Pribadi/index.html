Tentang Saya

Halo! Website ini dibuat sebagai proyek pemenuhan Lembar Kerja Peserta Didik (LKPD) pada mata pelajaran Informatika mengenai integrasi aplikasi web statis dengan simulasi REST API autentikasi di sisi klien (*Client-Side REST API*).

Di sini, saya memanfaatkan bakat dan struktur template responsif untuk menyajikan data portofolio pribadi, dokumentasi video edukatif, hingga pemetaan lokasi berbasis geospasial secara interaktif.

Sorotan Video & Dokumentasi

Berikut adalah sematan (*embed*) video interaktif dari YouTube sebagai bukti pemenuhan kompetensi penyisipan objek multimedia pihak ketiga menggunakan tag Iframe HTML5.

Lokasi Instansi Pendidikan

Berikut adalah peta interaktif lokasi SMA Negeri 8 Yogyakarta yang disematkan langsung menggunakan fitur *Embed Map* dari Google Maps.
